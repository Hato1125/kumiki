# KUMIKI

KUMIKI is a declarative UI library written in Zig that is **resolved at compile time**.  

### FEATURES

- **view**
  - `text`
  - `rect`
  - `image`
  - `spacer`
  - `row`
  - `column`
  - `stack`
  - `list`
  - `when`
  - `each`
- **animation**
- **timer**
- **async**

### REQUIREMENTS

- Zig 0.16.0 or later
